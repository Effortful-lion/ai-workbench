# 089 · 博客阅读页按布局规范重构（暗色两栏）

日期：2026-11-09 ｜ 分支：main ｜ 类型：refactor

## 一、规范 → 实现映射

| 规范要求 | 落地 |
|---|---|
| 左栏常驻 + 右侧正文两栏 | `lg:grid-cols-[190px_minmax(0,680px)]`，左栏 `lg:sticky lg:top-8`，滚动容器为 `.overflow-y-auto` |
| 窄屏折叠为顶部下拉 | `<details>`（`lg:hidden`），桌面不渲染；跳转后自动收起 |
| 标题 → 元信息 → 分隔线 → 正文 → 翻页 → 评论 | 严格按此顺序，删掉原文夹在标题后的摘要块 |
| 元信息主次分层 | 标签 `text-acc`；分类 `text-tx2`；ID/日期/字数时长/评论数统一 `text-tx3` |
| 统一左基线 | **移除** h1/h2 的 `border-l-2 pl-3`（原先把标题文字顶出基线 12px）；评论正文 `x=0`，头像 `lg:absolute -left-10`，楼层号 `lg:-right-10` |
| 8px 栅格间距 | 全部收敛到 16 / 24 / 32 / 48，见下表 |
| 翻页空状态降级 | 无内容侧不再渲染 `border`/`bg` 卡片，仅保留 `text-tx3/40` 的弱化文字 |
| 评论去虚线 | 移除 `border-b border-dashed`，改 `gap-8`（楼层）/ `gap-6`（楼内回复）留白 |
| 平滑锚点 | `scrollTo({ behavior: "smooth" })`，预留 16px 顶部呼吸位 |

## 二、间距刻度（全站唯一来源）

| 用途 | 值 |
|---|---|
| 标题 → 元信息 | 16 |
| 元信息 → 分隔线 | 24 |
| 分隔线 → 正文 | 32 |
| 章节之间（`section+section`） | 32 |
| 正文 → 翻页 / 翻页 → 评论 | 48 |
| 评论楼层之间 | 32 |
| 楼层内回复之间 | 24 |
| 目录缩进（二级/三级） | 16 / 24 |

## 三、修掉的既有问题

1. **标题不在基线上**：`border-l-2 border-acc pl-3` 让 h1/h2 文字比段落右移 12px，竖线看起来是装饰，实际破坏了对齐基准 —— 全部移除，改字号 + 留白区分层级。
2. **摘要与正文重复**：`post.summary` 单独渲染一段，而 KB 正文首段本就是这段（截图中可直接看到），属于规范禁止的「正文开头重复内容」。
3. **目录窄屏是双栏列表**：`max-[1020px]:columns-2` 只是把目录摊平在正文上方，不是可收起的下拉，长目录会顶走正文。
4. **翻页左右失衡**：无 prev/next 时仍渲染带边框的 `disabled` 按钮，视觉重量与有内容侧相同。
5. **评论主体离基线**：`flex gap-3` + 头像 30px 让正文右移 42px；楼内回复再套 `border-l pl-3`，二级回复累计偏移 54px。
6. **楼层号抖动**：楼层号与「回复」按钮同处 `ml-auto` 竞争，换行时位置漂移 —— 楼层号改为容器外绝对定位（`lg`），窄屏回到内联。

## 四、验证

- `pnpm --filter @aiwb/web build` 通过；`read_lints` 0 诊断。
- 1440×900：目录 sticky 全程不动，滚动到第二节时该项左标与文字同步变绿；正文/评论左边缘均为 x=375。
- 420×860：目录折叠为「目录 · 2 节」下拉；翻页两列压缩后仍无空卡片边框。

## 五、遗留

- 窄屏（<1024）评论头像无法外移（`-left-10` 会被屏幕边缘裁切），回落为内联，此时评论正文缩进 40px，不严格等于阅读基线 —— 桌面端满足规范，窄屏属物理限制下的折中。
- 博客面板内嵌阅读（`embedded`）同样吃 `lg` 断点：面板宽度通常 <1024，会走下拉目录而非左栏。若希望面板内也常驻左栏，需改用容器查询。
