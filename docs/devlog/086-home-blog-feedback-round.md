# 086 · 首页与博客反馈轮：快捷入口 / 登录评论 / 全屏语义 / 搜索历史 / KB 两态

日期：2026-11-09 ｜ 分支：main ｜ 类型：feature / UX

## 本轮 8 条反馈的处理

| # | 反馈 | 处理 |
|---|---|---|
| 1 | 首页缺博客快捷入口 | HeroState 快捷入口新增「博客」→ 打开 `blog` 面板 |
| 2 | 评论公开可见、发表需登录 | 服务端 `POST /blog/public/:u/:s/comments` 加 JwtAuthGuard，昵称取 `user.username`（不再接受客户端昵称）；前端未登录显示「去登录」，登录后显示「以 @username 身份评论」并走带鉴权 `api()` |
| 3 | 全屏只收对话栏、不收 header | App 布局：`fullscreen` 时隐藏 ChatColumn；PanelZone 去掉 `fixed inset-0`，改为占满 main 区域（TopBar 始终可见） |
| 4 | 「猜你想问」是否有必要 | 删除；由「最近提问」（本地历史）取代，避免静态建议占位 |
| 5 | 首页搜索历史 | `localStorage.aiwb-hero-history` 最近 6 条，提交时记录、点击重发、可一键清空；无历史时不渲染该区块 |
| 6 | 首页是否加内容 | 本轮不加（保持简洁）；输入框 + 快捷入口 + 最近提问已够，等有真实使用数据再定 |
| 7 | KB 博客状态只要两态两操作 | 已发布 → `下架`；无状态/已下架 → `发布`。移除「移除」「重新上架」与「已下架」徽标；下架内部置 archived，公开页不可见，再点发布按 KB 最新原文重新上架 |
| 8 | 卡片下方进度条含义 | 是**字数刻度**（按列表最长一篇归一化的正文长度，原型里代表长文权重）。含义不直观，已加原生 tooltip「字数刻度：本文 N 字」；是否换成阅读时长或删除待定 |

## 验证

- shared/server/web `tsc` + 构建全绿。
- 评论鉴权：未登录 POST 返回 401；登录 POST 落库 `nickname = admin`（测试评论已清理）。
- 无头渲染阅读页：出现「评论公开可见，发表评论需要登录 / 去登录」、目录与上下篇正常。

## 备注

- 评论人信息完全由登录态决定，客户端不再传昵称；游客只读。
- 首页历史存本地，不落库（未登录/换设备不共享）。

## 补丁：全屏未生效的根因

上一版用 `hidden` 隐藏对话栏，但 class 串里同时存在 `lg:flex`，桌面端 `lg:flex` 覆盖 `hidden`，导致对话栏始终显示。
改为条件渲染（全屏时不渲染 ChatColumn），并用 CDP 实测：全屏后 main.top=52（header 保留）、main.width=视口宽、对话输入框不存在；退出后恢复。
