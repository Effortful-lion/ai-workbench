# 开发日志规范

每个模块 / 重要里程碑一篇，文件名：`NNN-模块名.md`（编号按开发顺序）。

## 模板

```markdown
# NNN · 模块名

- 日期：YYYY-MM-DD
- 状态：进行中 / 已完成 / 暂停

## 目标
本模块要解决的问题与验收标准。

## 决策
开发过程中拍板的技术选择（含被否决方案及原因）。

## 实现
关键改动点，指向具体文件/代码位置。不贴大段代码。

## 验证
如何验证的：命令、接口、页面、结果。

## 遗留
已知问题、TODO、延后期数。
```

## 原则

- 写完一个模块立即记录，不补记、不合并记。
- 决策栏写"为什么"，实现栏只写"在哪里"。
- 版本变更（对外可感知的）另记 `change-log/`，遵循 Keep a Changelog。
