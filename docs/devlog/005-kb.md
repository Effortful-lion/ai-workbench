# 005 · kb 知识库（RAG）

- 日期：2026-11-02
- 状态：✅ 完成（后端 curl + 前端浏览器端到端全 PASS）

## 目标

落地「能力即工具」的知识底座：文档入库 → 切分 → embedding → 向量检索，并把检索包装成
对话能力。验收标准：

- 文本类文档上传后自动切分、向量化、可检索；失败有明确状态。
- 数据按用户隔离，越权读写一律拒绝。
- 面板支持终端文件树式浏览、选文件/粘贴/拖拽上传、删除。
- 检索即对话：输入问题 → AI 答案 + `[n]` 引用片段。
- Agent 可勾选 `kb.search` / `kb.ingest` 在对话里检索或记录知识。

## 决策

1. **Qdrant REST 直连，不引 SDK**：单节点只用到 collection / upsert / search / delete 四个接口，
   `fetch` 足够；集合按向量维度命名 `kb_chunks_d<dim>`，避免本地 256 维与真实模型向量维度冲突。
2. **Embedding 双路降级**：优先复用「模型管理」里名字含 `embed` 且非 `mock://` 的模型走
   OpenAI 兼容 `/embeddings`；无可用模型或调用失败时，用本地确定性特征哈希（中文单字 + 二元组、
   英文词，256 维 L2 归一化）。无 key 也能演示「检索真的能命中」，且向量可重复。
3. **切分 ~500 字滑窗、重叠 100 字**：优先在窗口尾部的换行 / 句号 / 分号处断开，减少句子被腰斩；
   一期不引 LangChain 文本分割器，规则简单可预期。
4. **ask 的降级策略**：先检索 topK，再交给对话模型生成答案；当前挑到的模型是 `mock://` 或没有
   真实模型时，直接输出「抽取式摘要 + 引用」而不是让 mock 返回 `pong`——保证演示路径完整。
   `source` 字段区分 `llm` / `extractive`，前端可见。
5. **上传一期只支持文本类**：`.txt/.md/.csv/.json/.log/.yml` 等；原文存档到
   `data/uploads/<userId>/<docId>.txt`，便于追溯与后续重建索引。PDF/DOCX 解析留二期。
6. **隔离三层**：REST 守卫 `kb:read/write`；DB 查询限定 `owner_id`；Qdrant 检索 filter
   `payload.user_id`。删除文档时按 `doc_id` 清理所有维度集合里的点。
7. **KbModule 复用 ChatService.pickModel**：不在 kb 里复制「选模型」的优先级逻辑；
   `KbModule` 导入 `ChatModule`，无循环依赖。
8. **面板状态留在组件内**：KB 面板生命周期短，用局部 `useState` 即可，不新增全局 store。
9. **前端不 import `@aiwb/shared` 的运行时函数**：`shared` 目前按 `nodenext` 构建为 CJS，Vite
   以 ESM 直接服务 `/@fs` 时 named export 识别失败（首次浏览器验证即空白页）。写权限判断沿用
   `ModelsPanel` 的 `role === owner|member`，服务端 `kb:write` 仍兜底；双格式构建列入遗留。

- curl（owner）：
  - ingest「部署手册.md」→ `status=embedded, chunkCount=1`。
  - `POST /kb/search`「服务端默认端口是多少」→ 命中 1 条，score 0.241，`embedding=local`。

  - member alice：documents=[]、search hits=[]（用户隔离 ✓）；无 token → 401。

  1. `kbtest` 登录 → 首页 chip「打开知识库」→ 面板出现 `~/kb · AI 知识库`。
  2. 「+ 粘贴文本」入库 `kbtest.md`（57B）→ 列表显示 `1 chunks · 已索引`。
  3. 问「项目代号是什么」→ 回答含「蓝鲸」，`citations:1`，引用 `[1] 《kbtest.md》 片段 #0 · 0.468`。

  新建标签页恢复 960×680 后全部通过；非产品 bug。验证账号：`kbtest / kbtest123`（member）。

## 遗留

- PDF / DOCX / URL 导入与文件类型探测（mammoth / pdf-parse）二期。
- 设计里的「把文件拖到对话列直接入库」未做；当前只支持拖到知识库面板。
- Qdrant 不可达时检索静默空结果，无 SQLite FTS 本地兜底。
- 重新索引、批量删除、文档原文预览、chunk 分页未做。
- `@aiwb/shared` CJS/ESM 双构建（让前端也能安全复用 `hasPermission` 等运行时函数）。
- `ask` 为一次性返回，未接 WS 流式；真实模型下的 RAG 质量评估未做。
