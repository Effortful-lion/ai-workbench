# 需求准备

既是个人工作台也是个人网站

## 首页 —— 这个后面再设计

可以是一个巨大的 AI 对话框 + 招呼语 + 动态推荐等

## AI Agent 助手 —— 首页（对应的就是首页的AI 对话框） + 整个网站提供 cli 命令行工具 + 全站可调出/隐藏 + 创建 Agent + cli 用于 agent 与系统进行交互 + 网站整体以智能化为主，无需用户手动操作（自然这里需要根据用户权限限制 agent 权限）

## 用户模块 —— 主要负责游客注册信息管理 + 用户和本人的权限隔离（只能看到个人简历、百宝箱等， 部分功能也只提供只读权限）

## 个人简历 —— 非 doc/pdf 类的简历，而是具有个性化的页面 + 真实的个人简历信息

## 个人动态 —— 主要负责展示用户的动态，比如： 项目更新、 代码提交、 文档更新、 个人经历、 生活经历...等

## 百宝箱 —— 提供多种工具链接/工具等用于工作提效的：二进制文件、链接、安装包、网站、软件等

## 项目管理 —— 前期提供项目文档等资料的创建、删除、更新的功能（区别文档库， 特定对项目文档管理）。后期直接对标git管理

## 代码管理 —— 前期提供项目代码上传、下载、查看等功能。后期直接对标git管理（甚至以后可以借助 github cli）

## 日程管理 —— 主要实现 任务-时间-通知提醒 管理的功能 + 站内信 + 邮件

## 商业化管理 —— 主要负责项目的商业化事项（支付、广告、订阅等）

## 客户管理 —— 主要负责项目的客户管理事项

## 邮件管理 —— 主要负责聚合各个邮件来源的邮件 + AI分析后提供智能分类 + 邮件回复（可选）

## 流水线工厂 —— 主要负责各种领域的 sop 管理和实际生产操作（比如： 漫剧生成、 小红书爆款文案生成等）

## 文档库 —— 主要负责存储和管理项目相关的知识、文档、代码、个人经验等资源，支持文件的各种操作。

## AI 知识库 —— 主要负责实现文档库的智能检索功能 + 会话管理

## 模型管理 —— 主要负责AI大模型的管理，主要是为了方便我自己快速使用各种厂商的模型
